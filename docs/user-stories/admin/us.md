# User Stories - Administrador del Sistema

### US1 - Registrar cuenta de usuario administrativo (Priority: P1)
Como Administrador, quiero registrar cuentas para roles internos (Guía, Gestor de Destino, Admin), para controlar quién tiene acceso a funciones sensibles de la plataforma.

### US2 - Aprobar registro de Prestador de Servicios (Priority: P1)
Como Administrador, quiero revisar y aprobar las solicitudes de registro de nuevos prestadores de servicios, para verificar su legitimidad antes de que publiquen oferta turística en la plataforma.

### US3 - Asignar rol a un usuario (Priority: P1)
Como Administrador, quiero asignar o modificar el rol de un usuario existente, para ajustar sus permisos de acceso según su función real en el sistema.

### US4 - Bloquear o suspender cuenta de usuario (Priority: P1)
Como Administrador, quiero bloquear o suspender temporalmente una cuenta, para impedir el acceso de usuarios que incumplan las políticas de uso o representen un riesgo de seguridad.

### US5 - Eliminar cuenta de usuario (Priority: P2)
Como Administrador, quiero eliminar o desactivar permanentemente una cuenta, para cumplir con solicitudes de baja o con la normativa de protección de datos (Ley 1581 de 2012).

### US6 - Ver listado de usuarios registrados (Priority: P1)
Como Administrador, quiero visualizar el listado completo de usuarios con su rol y estado, para tener control general sobre quién está activo en la plataforma.

### US7 - Buscar usuario específico (Priority: P2)
Como Administrador, quiero buscar un usuario por nombre, rol o identificación, para gestionar su cuenta de forma rápida sin recorrer todo el listado.

### US8 - Restablecer contraseña de usuario (Priority: P2)
Como Administrador, quiero restablecer la contraseña de un usuario que ha perdido acceso, para garantizar continuidad del servicio sin comprometer la seguridad de la cuenta.

### US9 - Ver indicadores globales de la plataforma (Priority: P1)
Como Administrador, quiero visualizar indicadores globales de uso (usuarios activos, reservas totales, prestadores registrados, disponibilidad del sistema), para monitorear la salud general de la plataforma.

### US10 - Generar reportes de auditoría (Priority: P1)
Como Administrador, quiero generar reportes de auditoría sobre acciones críticas realizadas en el sistema (altas, bajas, cambios de rol, anomalías gestionadas), para mantener trazabilidad y cumplir con los requisitos normativos de seguridad.

### US11 - Detectar y visualizar anomalías del sistema (Priority: P1)
Como Administrador, quiero visualizar las anomalías detectadas automáticamente (accesos sospechosos, caídas de servicio, picos anómalos de solicitudes), para identificar riesgos operativos o de seguridad de forma oportuna.

### US12 - Clasificar y priorizar una anomalía (Priority: P2)
Como Administrador, quiero clasificar una anomalía detectada según su severidad, para decidir qué casos requieren atención inmediata y cuáles pueden programarse.

### US13 - Marcar anomalía como resuelta (Priority: P1)
Como Administrador, quiero cambiar el estado de una anomalía a "resuelta" una vez atendida, para mantener actualizado el panel de monitoreo y conservar el historial de incidentes.

### US14 - Configurar alertas de anomalías (Priority: P2)
Como Administrador, quiero configurar umbrales para la generación automática de alertas (por ejemplo, número de solicitudes fallidas o caída de disponibilidad), para anticipar incidentes antes de que afecten a los usuarios.

### US15 - Moderar reseñas reportadas (Priority: P2)
Como Administrador, quiero revisar y moderar reseñas que hayan sido reportadas como ofensivas o falsas, para mantener la confiabilidad de la información y proteger a los prestadores de servicios de daños reputacionales injustificados.

### US16 - Monitorear disponibilidad del sistema en tiempo real (Priority: P1)
Como Administrador, quiero visualizar el estado de disponibilidad de los servicios de la plataforma en tiempo real, para detectar caídas o degradación del servicio antes de que impacten masivamente a los usuarios.

### US17 - Registrar reporte de seguridad (Priority: P1)
Como Administrador, quiero registrar un reporte de seguridad cuando un turista o prestador informe una situación de riesgo (robo, acoso, accidente, zona insegura), para dejar constancia oficial y activar el protocolo de atención correspondiente.

### US18 - Dar seguimiento y cerrar un reporte de seguridad (Priority: P1)
Como Administrador, quiero actualizar el estado de un reporte de seguridad (en proceso, atendido, cerrado) y asignarlo a la entidad responsable, para garantizar que cada incidente tenga una resolución trazable.
